# Wuhu UI 0.1 版本发布说明

发布日期：2026-11-20 · 版本：0.0.1

## 版本范围

本次发布包含 31 个独立组件包与 `@wuhu-vue-ui/core`，覆盖基础能力、视觉表达、交互增强与数据展示四类场景。

- 组件保持独立发布，可按需安装。
- 所有包提供 ESM、类型声明与独立样式文件。
- 新增 `ContextMenu`，统一右键菜单的定位、键盘导航与焦点恢复。

## 升级说明

1. 从 0.0.1-rc 升级时，请同步更新 `@wuhu-vue-ui/core` 与全部组件包版本。
2. `Loading` 已移除 `lockScroll`，全屏显示时默认锁定滚动。
3. `ContextMenu` 的事件参数不包含业务上下文，动态菜单请在打开前准备好 `items`。

## 回滚方案

- 灰度范围：内部工作区，10% 流量。
- 回滚条件：接口错误率连续 5 分钟超过 1%。
- 回滚操作：将 `release` 分支回退到上一稳定 tag，并重新发布静态资源。
