# @wuhu-vue-ui/tiptap-editor

Ready-to-use rich text editor built on Tiptap for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/tiptap-editor
# 或
npm install @wuhu-vue-ui/tiptap-editor
```

## 使用

```ts
import { TiptapEditor } from '@wuhu-vue-ui/tiptap-editor'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/tiptap-editor/style.css`。

完整文档与示例：[docs/components/tiptap-editor.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/tiptap-editor.md)
