# @wuhu-vue-ui/slider-captcha

A canvas-based slide puzzle captcha for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/slider-captcha
# 或
npm install @wuhu-vue-ui/slider-captcha
```

## 使用

```ts
import { SliderCaptcha } from '@wuhu-vue-ui/slider-captcha'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/slider-captcha/style.css`。

完整文档与示例：[docs/components/slider-captcha.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/slider-captcha.md)
