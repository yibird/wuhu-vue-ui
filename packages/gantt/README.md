# @wuhu-vue-ui/gantt

Extensible, interactive Gantt chart for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/gantt
# 或
npm install @wuhu-vue-ui/gantt
```

## 使用

```ts
import { Gantt } from '@wuhu-vue-ui/gantt'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/gantt/style.css`。

完整文档与示例：[docs/components/gantt.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/gantt.md)
