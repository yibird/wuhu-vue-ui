# @wuhu-vue-ui/number-ticker

Animated rolling number component for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/number-ticker
# 或
npm install @wuhu-vue-ui/number-ticker
```

## 使用

```ts
import { NumberTicker } from '@wuhu-vue-ui/number-ticker'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/number-ticker/style.css`。

完整文档与示例：[docs/components/number-ticker.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/number-ticker.md)
