# @wuhu-vue-ui/code-editor

Monaco-powered code editor component for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/code-editor
# 或
npm install @wuhu-vue-ui/code-editor
```

## 使用

```ts
import { CodeEditor } from '@wuhu-vue-ui/code-editor'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/code-editor/style.css`。

> 需要自行安装 peer 依赖：`monaco-editor`。

完整文档与示例：[docs/components/code-editor.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/code-editor.md)
