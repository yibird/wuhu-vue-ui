# @wuhu-vue-ui/lazy-container

IntersectionObserver powered lazy container for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/lazy-container
# 或
npm install @wuhu-vue-ui/lazy-container
```

## 使用

```ts
import { LazyContainer } from '@wuhu-vue-ui/lazy-container'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/lazy-container/style.css`。

完整文档与示例：[docs/components/lazy-container.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/lazy-container.md)
