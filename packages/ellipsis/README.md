# @wuhu-vue-ui/ellipsis

Multi-line text ellipsis with expandable content and tooltip for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/ellipsis
# 或
npm install @wuhu-vue-ui/ellipsis
```

## 使用

```ts
import { Ellipsis } from '@wuhu-vue-ui/ellipsis'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/ellipsis/style.css`。

完整文档与示例：[docs/components/ellipsis.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/ellipsis.md)
