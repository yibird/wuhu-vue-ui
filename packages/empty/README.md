# @wuhu-vue-ui/empty

Empty state placeholder with built-in illustration for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/empty
# 或
npm install @wuhu-vue-ui/empty
```

## 使用

```ts
import { Empty } from '@wuhu-vue-ui/empty'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/empty/style.css`。

完整文档与示例：[docs/components/empty.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/empty.md)
