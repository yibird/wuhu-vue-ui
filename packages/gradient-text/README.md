# @wuhu-vue-ui/gradient-text

Configurable gradient text with optional animation for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/gradient-text
# 或
npm install @wuhu-vue-ui/gradient-text
```

## 使用

```ts
import { GradientText } from '@wuhu-vue-ui/gradient-text'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/gradient-text/style.css`。

完整文档与示例：[docs/components/gradient-text.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/gradient-text.md)
