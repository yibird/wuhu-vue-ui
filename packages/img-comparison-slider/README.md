# @wuhu-vue-ui/img-comparison-slider

Accessible before/after image comparison slider for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/img-comparison-slider
# 或
npm install @wuhu-vue-ui/img-comparison-slider
```

## 使用

```ts
import { ImgComparisonSlider } from '@wuhu-vue-ui/img-comparison-slider'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/img-comparison-slider/style.css`。

完整文档与示例：[docs/components/img-comparison-slider.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/img-comparison-slider.md)
