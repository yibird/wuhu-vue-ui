# @wuhu-vue-ui/time

Auto-updating relative time component for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/time
# 或
npm install @wuhu-vue-ui/time
```

## 使用

```ts
import { Time } from '@wuhu-vue-ui/time'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/time/style.css`。

完整文档与示例：[docs/components/time.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/time.md)
