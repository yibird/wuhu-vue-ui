# @wuhu-vue-ui/org-tree

Interactive organization tree with pan, zoom, expansion and drag-to-reparent for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/org-tree
# 或
npm install @wuhu-vue-ui/org-tree
```

## 使用

```ts
import { OrgTree } from '@wuhu-vue-ui/org-tree'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/org-tree/style.css`。

完整文档与示例：[docs/components/org-tree.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/org-tree.md)
