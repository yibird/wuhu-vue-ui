# @wuhu-vue-ui/scrollbar

A cross-browser custom scrollbar for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/scrollbar
# 或
npm install @wuhu-vue-ui/scrollbar
```

## 使用

```ts
import { Scrollbar } from '@wuhu-vue-ui/scrollbar'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/scrollbar/style.css`。

完整文档与示例：[docs/components/scrollbar.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/scrollbar.md)
