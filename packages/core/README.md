# @wuhu-vue-ui/core

Shared utilities and Vue composables for Wuhu UI packages.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/core
# 或
npm install @wuhu-vue-ui/core
```

## 使用

```ts
import { useCopy } from '@wuhu-vue-ui/core'
```

更多信息：[Wuhu Vue UI](https://github.com/yibird/wuhu-vue-ui#readme)
