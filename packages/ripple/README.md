# @wuhu-vue-ui/ripple

Material-style ripple effect component and directive for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/ripple
# 或
npm install @wuhu-vue-ui/ripple
```

## 使用

```ts
import { Ripple } from '@wuhu-vue-ui/ripple'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/ripple/style.css`。

完整文档与示例：[docs/components/ripple.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/ripple.md)
