# @wuhu-vue-ui/motion-group

Animated list reordering for Vue 3, built on TransitionGroup.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/motion-group
# 或
npm install @wuhu-vue-ui/motion-group
```

## 使用

```ts
import { MotionGroup } from '@wuhu-vue-ui/motion-group'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/motion-group/style.css`。

完整文档与示例：[docs/components/motion-group.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/motion-group.md)
