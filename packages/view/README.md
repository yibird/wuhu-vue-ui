# @wuhu-vue-ui/view

Composable page layout shell with header, sider, content and footer for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/view
# 或
npm install @wuhu-vue-ui/view
```

## 使用

```ts
import { View } from '@wuhu-vue-ui/view'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/view/style.css`。

完整文档与示例：[docs/components/view.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/view.md)
