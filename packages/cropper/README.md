# @wuhu-vue-ui/cropper

Image cropper for Vue 3, powered by Cropper.js.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/cropper
# 或
npm install @wuhu-vue-ui/cropper
```

## 使用

```ts
import { Cropper } from '@wuhu-vue-ui/cropper'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/cropper/style.css`。

完整文档与示例：[docs/components/cropper.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/cropper.md)
