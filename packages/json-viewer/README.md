# @wuhu-vue-ui/json-viewer

Read-only, auto-formatted JSON viewer built on CodeEditor and Monaco.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/json-viewer
# 或
npm install @wuhu-vue-ui/json-viewer
```

## 使用

```ts
import { JsonViewer } from '@wuhu-vue-ui/json-viewer'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/json-viewer/style.css`。

> 需要自行安装 peer 依赖：`monaco-editor`。

完整文档与示例：[docs/components/json-viewer.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/json-viewer.md)
