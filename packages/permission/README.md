# @wuhu-vue-ui/permission

Permission guard component and directive for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/permission
# 或
npm install @wuhu-vue-ui/permission
```

## 使用

```ts
import { Permission } from '@wuhu-vue-ui/permission'
```

完整文档与示例：[docs/components/permission.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/permission.md)
