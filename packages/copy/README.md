# @wuhu-vue-ui/copy

Accessible clipboard copy trigger for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/copy
# 或
npm install @wuhu-vue-ui/copy
```

## 使用

```ts
import { Copy } from '@wuhu-vue-ui/copy'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/copy/style.css`。

完整文档与示例：[docs/components/copy.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/copy.md)
