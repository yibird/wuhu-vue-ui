# @wuhu-vue-ui/highlight

Safe keyword highlighting for Vue 3 with scoped slots.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/highlight
# 或
npm install @wuhu-vue-ui/highlight
```

## 使用

```ts
import { Highlight } from '@wuhu-vue-ui/highlight'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/highlight/style.css`。

完整文档与示例：[docs/components/highlight.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/highlight.md)
