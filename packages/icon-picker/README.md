# @wuhu-vue-ui/icon-picker

Grouped, searchable and virtualized icon picker for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/icon-picker
# 或
npm install @wuhu-vue-ui/icon-picker
```

## 使用

```ts
import { IconPicker } from '@wuhu-vue-ui/icon-picker'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/icon-picker/style.css`。

完整文档与示例：[docs/components/icon-picker.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/icon-picker.md)
