# @wuhu-vue-ui/exception

Ready-to-use exception pages for 400, 403, 404 and 500 errors in Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/exception
# 或
npm install @wuhu-vue-ui/exception
```

## 使用

```ts
import { Exception } from '@wuhu-vue-ui/exception'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/exception/style.css`。

完整文档与示例：[docs/components/exception.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/exception.md)
