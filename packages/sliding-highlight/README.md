# @wuhu-vue-ui/sliding-highlight

Animated sliding indicator navigation for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/sliding-highlight
# 或
npm install @wuhu-vue-ui/sliding-highlight
```

## 使用

```ts
import { SlidingHighlight } from '@wuhu-vue-ui/sliding-highlight'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/sliding-highlight/style.css`。

完整文档与示例：[docs/components/sliding-highlight.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/sliding-highlight.md)
