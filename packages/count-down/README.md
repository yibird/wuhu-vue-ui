# @wuhu-vue-ui/count-down

Drift-corrected countdown timer component for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/count-down
# 或
npm install @wuhu-vue-ui/count-down
```

## 使用

```ts
import { CountDown } from '@wuhu-vue-ui/count-down'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/count-down/style.css`。

完整文档与示例：[docs/components/count-down.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/count-down.md)
