# @wuhu-vue-ui/dock

macOS-style dock navigation with pointer magnification for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/dock
# 或
npm install @wuhu-vue-ui/dock
```

## 使用

```ts
import { Dock } from '@wuhu-vue-ui/dock'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/dock/style.css`。

完整文档与示例：[docs/components/dock.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/dock.md)
