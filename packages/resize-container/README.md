# @wuhu-vue-ui/resize-container

ResizeObserver powered element size listener for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/resize-container
# 或
npm install @wuhu-vue-ui/resize-container
```

## 使用

```ts
import { ResizeContainer } from '@wuhu-vue-ui/resize-container'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/resize-container/style.css`。

完整文档与示例：[docs/components/resize-container.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/resize-container.md)
