# @wuhu-vue-ui/command-menu

Searchable command palette with a custom filter hook for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/command-menu
# 或
npm install @wuhu-vue-ui/command-menu
```

## 使用

```ts
import { CommandMenu } from '@wuhu-vue-ui/command-menu'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/command-menu/style.css`。

完整文档与示例：[docs/components/command-menu.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/command-menu.md)
