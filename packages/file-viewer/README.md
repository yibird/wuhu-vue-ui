# @wuhu-vue-ui/file-viewer

A themeable, internationalized file preview component for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/file-viewer
# 或
npm install @wuhu-vue-ui/file-viewer
```

## 使用

```ts
import { FileViewer } from '@wuhu-vue-ui/file-viewer'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/file-viewer/style.css`。

> 需要自行安装 peer 依赖：`pdfjs-dist`。

完整文档与示例：[docs/components/file-viewer.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/file-viewer.md)
