# @wuhu-vue-ui/loading

Loading spinner and fullscreen overlay with five built-in animations for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/loading
# 或
npm install @wuhu-vue-ui/loading
```

## 使用

```ts
import { Loading } from '@wuhu-vue-ui/loading'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/loading/style.css`。

完整文档与示例：[docs/components/loading.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/loading.md)
