# @wuhu-vue-ui/error-boundary

Composable error boundary with reset support for Vue 3.

Wuhu Vue UI 组件库的一部分。

## 安装

```bash
pnpm add @wuhu-vue-ui/error-boundary
# 或
npm install @wuhu-vue-ui/error-boundary
```

## 使用

```ts
import { ErrorBoundary } from '@wuhu-vue-ui/error-boundary'
```

浏览器入口会自动引入样式；也可以单独引入 `@wuhu-vue-ui/error-boundary/style.css`。

完整文档与示例：[docs/components/error-boundary.md](https://github.com/yibird/wuhu-vue-ui/blob/main/docs/components/error-boundary.md)
